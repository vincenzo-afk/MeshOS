# Contributing to MeshOS

Thank you for your interest in contributing to **MeshOS**! Please follow these guidelines to ensure a smooth contribution process.

## Code of Conduct
By participating, you are expected to uphold our Code of Conduct. Please report unacceptable behavior.

## Pull Request Process
1. Ensure any install or build dependencies are removed before the end of a layer build.
2. Update the README.md with details of changes if applicable.
3. The PR will be merged once the CI checks pass and code review is complete.
